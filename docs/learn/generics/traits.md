# Traits

A generic that finds the smallest cell of a list must compare two cells. Numbers
compare with `<`, but a struct of the program compares as the program tells it to. A
*trait* names the functions a kind must have; a kind parameter that needs the trait
takes the kinds that have them.

```zaka
ငယ်စဉ်ကြီးလိုက်စီနိုင်သော ဟူသည့် ဂုဏ်သတ္တိ သည် ယေဘုယျဒေတာအမျိုးအစား A ကိုအစားထိုးသုံးနိုင်၍ ၎င်းတွင် အောက်ပါလုပ်ဆောင်ချက်များ ပါဝင်ရမည်။
လုပ်ဆောင်ချက် ငယ်သလား သည်
က ဟူသော A တစ်ခု ကို လည်းကောင်း ခ ဟူသော A တစ်ခု ကို လည်းကောင်း
လက်ခံပြီး မှန်မှားတန်ဖိုး တစ်ခု ကို ပြန်ပေးမည်။
ဂုဏ်သတ္တိတွင် ပါသော လုပ်ဆောင်ချက်များ ပြီးဆုံးပါပြီး။

လူ ဟူသော ဒေတာအစုအဝေးတွင်
နာမည် ဟူသော စာသား တစ်ခု နှင့် အသက် ဟူသော ကိန်းပြည့် တစ်ခု
တို့ပါဝင်ပြီး မျိုးပြပစ္စည်းမှာ ယောက် ဖြစ်သည်။

လူ တွင် ငယ်စဉ်ကြီးလိုက်စီနိုင်သော ဂုဏ်သတ္တိရှိစေရန် အောက်ပါလုပ်ဆောင်ချက်များ ကို ထည့်သွင်းမည်။
လုပ်ဆောင်ချက် ငယ်သလား သည်
က ဟူသော လူ တစ်ယောက် ကို လည်းကောင်း ခ ဟူသော လူ တစ်ယောက် ကို လည်းကောင်း
လက်ခံပြီး အောက်ပါတို့ကို လုပ်ဆောင်ကာ မှန်မှားတန်ဖိုး တစ်ခု ကို ပြန်ပေးမည်။
(က ၏ အသက်) < (ခ ၏ အသက်) ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
ထည့်သွင်းမည့် လုပ်ဆောင်ချက်များ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် အငယ်ဆုံး<T: ငယ်စဉ်ကြီးလိုက်စီနိုင်သော> သည်
ကိန်းများ ဟူသော T စာရင်း တစ်ခု ကို လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ T တစ်ခု ကို ပြန်ပေးမည်။
ကိန်းရှင် အငယ် သည် ကိန်းများ ၏ အကွက် ၀ ဖြစ်ပါစေ။
ကိန်းများ ၏ အကွက်တိုင်း ကို ဝ အနေဖြင့် ယူ၍ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
အကယ်၍ ငယ်သလား(ဝ၊ အငယ်) ဖြစ်လျှင် အငယ် ကို ဝ ဟု ထားမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
အငယ် ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် လူများ သည် [လူ(နာမည်: "အေးအေး"၊ အသက်: ၃၀)၊ လူ(နာမည်: "မောင်မောင်"၊ အသက်: ၂၄)] ဖြစ်ပါစေ။
အငယ်ဆုံး(လူများ) ၏ နာမည် ကို ပြသမည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
မောင်မောင်
```

The three parts:

- **The trait.** `ငယ်စဉ်ကြီးလိုက်စီနိုင်သော ဂုဏ်သတ္တိ` ("the trait of what can be put in
  order") names its kinds as a generic does. Its first kind, `A`, is the kind that has
  the trait. Each function head inside it ends at its result, with no block.
- **The trait block.** `လူ တွင် … ဂုဏ်သတ္တိရှိစေရန် … ထည့်သွင်းမည်` ("to give လူ the trait,
  add these functions") holds the functions for `လူ`. The compiler checks that the block
  holds each function of the trait, with `လူ` in place of `A`.
- **The constraint.** `<T: ငယ်စဉ်ကြီးလိုက်စီနိုင်သော>` tells that `T` needs the trait.
  Each call checks it for the kind it gives `T`, before the compiler makes the function.

## A trait with no block

A kind has a trait when the program has its functions, block or no block. A plain
function `ငယ်သလား` on two `ကိန်းပြည့်` values gives `ကိန်းပြည့်` the trait. The block is
a check: it names the functions of the trait, and the compiler holds the block to it.

When a kind lacks a function, the call reports it, with the function:

```zaka-error ZK0343
ငယ်စဉ်ကြီးလိုက်စီနိုင်သော ဟူသည့် ဂုဏ်သတ္တိ သည် ယေဘုယျဒေတာအမျိုးအစား A ကိုအစားထိုးသုံးနိုင်၍ ၎င်းတွင် အောက်ပါလုပ်ဆောင်ချက်များ ပါဝင်ရမည်။
လုပ်ဆောင်ချက် ငယ်သလား သည်
က ဟူသော A တစ်ခု ကို လည်းကောင်း ခ ဟူသော A တစ်ခု ကို လည်းကောင်း
လက်ခံပြီး မှန်မှားတန်ဖိုး တစ်ခု ကို ပြန်ပေးမည်။
ဂုဏ်သတ္တိတွင် ပါသော လုပ်ဆောင်ချက်များ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် ငယ်ရာ<T: ငယ်စဉ်ကြီးလိုက်စီနိုင်သော> သည်
က ဟူသော T တစ်ခု ကို လည်းကောင်း ခ ဟူသော T တစ်ခု ကို လည်းကောင်း
လက်ခံပြီး အောက်ပါတို့ကို လုပ်ဆောင်ကာ T တစ်ခု ကို ပြန်ပေးမည်။
အကယ်၍ ငယ်သလား(က၊ ခ) ဖြစ်လျှင် က ကို ပြန်ပေးမည်။
ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ငယ်ရာ(၁.၅၊ ၂.၅) ကို ပြသမည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

## Built-in traits

The traits of the operators come with the [prelude](../../manual/language/prelude.md),
the module each file sees with no import:

| Trait | Kinds |
| --- | --- |
| `ပေါင်းနိုင်သော` | numbers and text, which `+` takes |
| `နုတ်နိုင်သော`, `မြှောက်နိုင်သော`, `စားနိုင်သော` | numbers, which `-`, `*` and `/` take |
| `နံပါတ်နှင့်တူသော` | the kinds with the four above |
| `နှိုင်းယှဉ်နိုင်သော` | numbers and characters, which `< >` take |
| `တူမတူစစ်ဆေးနိုင်သော` | each kind, as `==` takes two values of one kind |
| `စာသားအဖြစ်ပြောင်းလဲပြသနိုင်သော` | each kind `ပြသမည်` prints |

```zaka
လုပ်ဆောင်ချက် စုစုပေါင်း<T: နံပါတ်နှင့်တူသော> သည်
ကိန်းများ ဟူသော T စာရင်း တစ်ခု ကို လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ T တစ်ခု ကို ပြန်ပေးမည်။
ကိန်းရှင် ပေါင်း သည် T တစ်ခု ဖြစ်၍ တန်ဖိုးသည် ကနဦးတန်ဖိုး ဖြစ်ပါစေ။
ကိန်းများ ၏ အကွက်တိုင်း ကို ဝ အနေဖြင့် ယူ၍ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ပေါင်း ကို ပေါင်း + ဝ ဟု ထားမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
ပေါင်း ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
စုစုပေါင်း([၁၊ ၂၊ ၃]) ကို ပြသမည်။
စုစုပေါင်း([၁.၅၊ ၂.၅]) ကို ပြသမည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
၆
၄.၀
```

A list of text has no `+` on its cells, so `စုစုပေါင်း(["က"])` stops at the call with
ZK0343, before the compiler reads the function for text.

## Operators on a struct of the program

A struct takes `+` when it has the function `+` stands for, `ပေါင်း`, on two of its
values; `<` calls `ငယ်မငယ်စစ်`, `==` calls `ညီမညီစစ်`, and printing calls
`စာသားအဖြစ်ပြောင်း`. The struct then has the trait of the operator too:

```zaka
ဗက်တာ ဟူသော ဒေတာအစုအဝေးတွင် x ဟူသော ကိန်းပြည့် တစ်ခု နှင့် y ဟူသော ကိန်းပြည့် တစ်ခု တို့ပါဝင်သည်။

လုပ်ဆောင်ချက် ပေါင်း သည်
က ဟူသော ဗက်တာ တစ်ခု ကို လည်းကောင်း ခ ဟူသော ဗက်တာ တစ်ခု ကို လည်းကောင်း
လက်ခံပြီး အောက်ပါတို့ကို လုပ်ဆောင်ကာ ဗက်တာ တစ်ခု ကို ပြန်ပေးမည်။
ဗက်တာ(x: (က ၏ x) + (ခ ၏ x)၊ y: (က ၏ y) + (ခ ၏ y)) ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် စာသားအဖြစ်ပြောင်း သည်
က ဟူသော ဗက်တာ တစ်ခု ကို လက်ခံပြီး အောက်ပါတို့ကို လုပ်ဆောင်ကာ စာသား တစ်ခု ကို ပြန်ပေးမည်။
"<{က ၏ x}၊ {က ၏ y}>" ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် စုစုပေါင်း<T: ပေါင်းနိုင်သော> သည်
ပထမ ဟူသော T တစ်ခု ကို လည်းကောင်း ကျန် ဟူသော T စာရင်း တစ်ခု ကို လည်းကောင်း
လက်ခံပြီး အောက်ပါတို့ကို လုပ်ဆောင်ကာ T တစ်ခု ကို ပြန်ပေးမည်။
ကိန်းရှင် ပေါင်းပြီး သည် ပထမ ဖြစ်ပါစေ။
ကျန် ၏ အကွက်တိုင်း ကို ဝ အနေဖြင့် ယူ၍ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ပေါင်းပြီး ကို ပေါင်းပြီး + ဝ ဟု ထားမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
ပေါင်းပြီး ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် က သည် ဗက်တာ(x: ၁၊ y: ၂) ဖြစ်ပါစေ။
က + က ကို ပြသမည်။
စုစုပေါင်း(က၊ [က၊ က]) ကို ပြသမည်။
စုစုပေါင်း("က"၊ ["ခ"]) ကို ပြသမည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
<၂၊ ၄>
<၃၊ ၆>
ကခ
```

## Traits that need traits

A trait can need other traits, in a notes block after its head. A kind has the trait
when it has those as well:

```text
စီနိုင်သောနံပါတ် ဟူသည့် ဂုဏ်သတ္တိ သည် ယေဘုယျဒေတာအမျိုးအစား A ကိုအစားထိုးသုံးနိုင်၍ ၎င်းတွင် အောက်ပါလုပ်ဆောင်ချက်များ ပါဝင်ရမည်။
ဤနေရာတွင် သတိပြုရန်မှာ
A တွင် နံပါတ်နှင့်တူသော ဂုဏ်သတ္တိ နှင့် ငယ်စဉ်ကြီးလိုက်စီနိုင်သော ဂုဏ်သတ္တိ တို့ ရှိသည်။
သတိပြုစရာများ ပြီးဆုံးပါပြီး။
ဂုဏ်သတ္တိတွင် ပါသော လုပ်ဆောင်ချက်များ ပြီးဆုံးပါပြီး။
```

The same notes block gives a generic function its constraints in words:
`T တွင် နံပါတ်နှင့်တူသော ဂုဏ်သတ္တိ ရှိသည်။` means what `<T: နံပါတ်နှင့်တူသော>` means.
