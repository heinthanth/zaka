# Functions as values

A function can be handed around like a number. `<name> ဟူသော လုပ်ဆောင်ချက်` ("the function
called *name*") is a function value: keep it in a variable, and a call through the
variable runs the function.

```zaka
လုပ်ဆောင်ချက် နှစ်ထပ် သည်
က ဟူသော ကိန်းပြည့် တစ်ခု ကို လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က * က ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
// the function, kept in a variable
ကိန်းရှင် ဖ သည် နှစ်ထပ် ဟူသော လုပ်ဆောင်ချက် ဖြစ်ပါစေ။
ဖ(၇) ကို ပြသမည်။
ဖ ဟူသော လုပ်ဆောင်ချက်ကို ၅ တို့ဖြင့် လုပ်ဆောင်သော ရလဒ် ကို ပြသမည်။
ဖ ကို ပြသမည်။      // the value itself
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
၄၉
၂၅
နှစ်ထပ် ဟူသော လုပ်ဆောင်ချက်
```

Each call form works through the variable: the name after `လုပ်ဆောင်ချက်`, the name before
`(`, and the arguments-first forms. A function value prints as the phrase that makes it.

## The kind of a function

A function value has a *function kind*. It reads like the header of the function, with
`သော` ("that") and `လုပ်ဆောင်ချက် အမျိုးအစား` ("function kind") at the end:

| Kind | Reads as |
| --- | --- |
| `ကိန်းပြည့် တစ်ခု ကို လက်ခံပြီး ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးသော လုပ်ဆောင်ချက် အမျိုးအစား` | "a function kind that accepts an integer and gives back an integer result" |
| `စာသား တစ်ခု ကို လက်ခံသော လုပ်ဆောင်ချက် အမျိုးအစား` | "a function kind that accepts text" |
| `ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးသော လုပ်ဆောင်ချက် အမျိုးအစား` | "a function kind that gives back an integer result" |
| `လုပ်ဆောင်ချက် အမျိုးအစား` | "a function kind": no parameters, no result |

The parameters have no names: each is its kind with its measure word and `ကို`, and two
or more each end in `လည်းကောင်း`, as in
`ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး`. A declaration
counts the whole kind with `တစ်ခု`, as other kinds:

```zaka
လုပ်ဆောင်ချက် ပေါင်း သည်
က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က + ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် လုပ် သည် ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးသော လုပ်ဆောင်ချက် အမျိုးအစား တစ်ခု ဖြစ်၍ တန်ဖိုးသည် ပေါင်း ဟူသော လုပ်ဆောင်ချက် ဖြစ်ပါစေ။
လုပ်(၂၊ ၃) ကို ပြသမည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
၅
```

## Passing a function

A parameter of a function kind takes a function from the caller. In a list of
parameters, the kind of such a parameter stands in parentheses, so its own parameters
do not mix with those of the list:

```zaka
လုပ်ဆောင်ချက် နှစ်ဆ သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က * ၂ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် နှစ်ထပ် သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က * က ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

// a new list: each cell changed with the function the caller gives
လုပ်ဆောင်ချက် ကွက်တိုင်း သည်
စ ဟူသော ကိန်းပြည့် စာရင်း တစ်ခု ကို လည်းကောင်း
ပြောင်း ဟူသော (ကိန်းပြည့် တစ်ခု ကို လက်ခံပြီး ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးသော လုပ်ဆောင်ချက် အမျိုးအစား) တစ်ခု ကို လည်းကောင်း
လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် စာရင်း တစ်ခု ကို ပြန်ပေးမည်။
ကိန်းရှင် အဖြေ သည် ကိန်းပြည့် စာရင်း တစ်ခု ဖြစ်၍ တန်ဖိုးသည် [] ဖြစ်ပါစေ။
စ ၏ အကွက်တိုင်း ကို တန် အနေဖြင့် ယူ၍ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
အဖြေ ထဲသို့ ပြောင်း(တန်) ကို ထည့်မည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
အဖြေ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် ဂဏန်း သည် [၁၊ ၂၊ ၃] ဖြစ်ပါစေ။
ကွက်တိုင်း ဟူသော လုပ်ဆောင်ချက်ကို ဂဏန်း၊ နှစ်ဆ ဟူသော လုပ်ဆောင်ချက် တို့ဖြင့် လုပ်ဆောင်သော ရလဒ် ကို ပြသမည်။
ကွက်တိုင်း ဟူသော လုပ်ဆောင်ချက်ကို ဂဏန်း၊ နှစ်ထပ် ဟူသော လုပ်ဆောင်ချက် တို့ဖြင့် လုပ်ဆောင်သော ရလဒ် ကို ပြသမည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
[၂၊ ၄၊ ၆]
[၁၊ ၄၊ ၉]
```

`ကွက်တိုင်း` does not know what each cell turns into: the function it is given decides.
The same idea sorts a list in each order. The sort asks the function `ရှေ့` ("comes
first") whether one number comes before another:

```zaka
လုပ်ဆောင်ချက် ငယ်စဉ် သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ မှန်မှားတန်ဖိုး တစ်ခု ကို ပြန်ပေးမည်။
က < ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် ကြီးစဉ် သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ မှန်မှားတန်ဖိုး တစ်ခု ကို ပြန်ပေးမည်။
က > ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် စီပေး သည်
ကိန်းများ ဟူသော ကိန်းပြည့် စာရင်း တစ်ခု ကို ဒေတာ ပြောင်းလဲရန် လည်းကောင်း ရှေ့ ဟူသော (ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး မှန်မှားတန်ဖိုး တစ်ခု ကို ပြန်ပေးသော လုပ်ဆောင်ချက် အမျိုးအစား) တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်မည်။
အကယ်၍ (ကိန်းများ ၏ အကွက်အရေအတွက်) == ၀ ဖြစ်လျှင် ပြန်ပေးမည်။
၁ မှ (ကိန်းများ ၏ အကွက်အရေအတွက်) - ၁ အထိ န အနေဖြင့် ရေတွက်၍ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် မ သည် န ဖြစ်ပါစေ။
// move the cell back while it comes before the cell in front of it
မ > ၀ && ရှေ့(ကိန်းများ ၏ အကွက် မ၊ ကိန်းများ ၏ အကွက် (မ - ၁)) ဖြစ်နေသရွေ့ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
```

## Naming a function kind

A function kind is long to write in each header. A [kind
alias](../structs/README.md#another-name-for-a-kind) names it once, and the name then
stands where the kind does. The alias is one word, so a list of parameters takes it with no
parentheses:

```zaka
ဒေတာအမျိုးအစား တွက်ချက် ကို ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးသော လုပ်ဆောင်ချက် အမျိုးအစား ဟုလည်း မှတ်ယူနိုင်ပါသည်။

လုပ်ဆောင်ချက် ပေါင်း သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က + ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် မြှောက် သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
```

## A table of functions

A list can hold function values. A call names the cell where it stands, after
`လုပ်ဆောင်ချက်`, so the table picks the function at run time. Here the cells follow the
members of an enumeration:

```zaka
လုပ်ငန်း ဟူသော ဒေတာအမျိုးအစားကွဲတွင် ပေါင်း၊ နုတ်၊ မြှောက် တို့ပါဝင်သည်။

လုပ်ဆောင်ချက် ပေါင်းပေး သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က + ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် နုတ်ပေး သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က - ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

လုပ်ဆောင်ချက် မြှောက်ပေး သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း ခ ဟူသော ကိန်းပြည့် တစ်ခု ကို လည်းကောင်း လက်ခံပြီး
အောက်ပါတို့ကို လုပ်ဆောင်ကာ ကိန်းပြည့် တစ်ခု ကို ပြန်ပေးမည်။
က * ခ ကို ပြန်ပေးမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းသေ ဂရစ် သည် [ပေါင်းပေး ဟူသော လုပ်ဆောင်ချက်၊ နုတ်ပေး ဟူသော လုပ်ဆောင်ချက်၊ မြှောက်ပေး ဟူသော လုပ်ဆောင်ချက်] ဖြစ်ပါစေ။
ကိန်းရှင် ခိုင်း သည် [လုပ်ငန်းများထဲမှ မြှောက်၊ လုပ်ငန်းများထဲမှ ပေါင်း၊ လုပ်ငန်းများထဲမှ နုတ်] ဖြစ်ပါစေ။
ခိုင်း ၏ အကွက်တိုင်း ကို ခု အနေဖြင့် ယူ၍ အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် အမှတ် သည် ခု ကို ကိန်းပြည့် တစ်ခု အဖြစ် ပြောင်းလဲသော ရလဒ် ဖြစ်ပါစေ။
"{ခု}: {(ဂရစ် ၏ အကွက် အမှတ်) ဟူသော လုပ်ဆောင်ချက်ကို ၆၊ ၃ တို့ဖြင့် လုပ်ဆောင်သော ရလဒ်}" ဟု ပြသမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
လုပ်ငန်းများထဲမှ မြှောက်: ၁၈
လုပ်ငန်းများထဲမှ ပေါင်း: ၉
လုပ်ငန်းများထဲမှ နုတ်: ၃
```

A struct field can hold a function value too, and a call names it the same, in
parentheses: `(ခလုတ် ၏ လုပ်) ဟူသော လုပ်ဆောင်ချက်ကို ၁ တို့ဖြင့် လုပ်ဆောင်မည်။`

## A function that can be missing

A function value holds a function on each call; Zaka has no NULL function. A variable of
a function kind declared with no value gets a function before its first call, as each
variable does:

```zaka-error ZK0722
ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် ဖ သည် ကိန်းပြည့် တစ်ခု ကို လက်ခံသော လုပ်ဆောင်ချက် အမျိုးအစား တစ်ခု ဖြစ်ပါစေ။
ဖ ဟူသော လုပ်ဆောင်ချက်ကို ၁ တို့ဖြင့် လုပ်ဆောင်မည်။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
error[ZK0722]: "ဖ" can be unset here: a path reaches this read with no value given to it
```

A function kind has no [initial value](../variables/README.md#the-initial-value) either:
no function is a fair pick for the program, so `ကနဦးတန်ဖိုး` for it is the error ZK0479.
Where a function can be missing, its kind states it with an
[optional](../optionals/README.md), and the program asks before the call:

```zaka
လုပ်ဆောင်ချက် ပြ သည် က ဟူသော ကိန်းပြည့် တစ်ခု ကို လက်ခံပြီး အောက်ပါတို့ကို လုပ်ဆောင်မည်။
က ကို ပြသမည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။

ပရိုဂရမ်သည် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် ဖ သည် (ကိန်းပြည့် တစ်ခု ကို လက်ခံသော လုပ်ဆောင်ချက် အမျိုးအစား) ရှိကောင်းရှိနိုင်သော ဒေတာဆဲလ် တစ်ခု ဖြစ်၍ တန်ဖိုးသည် အလွတ် ဖြစ်ပါစေ။
အကယ်၍ ဖ ထဲတွင် ဒေတာ မရှိလျှင် "မရှိ" ဟု ပြသမည်။
ဖ ကို ပြ ဟူသော လုပ်ဆောင်ချက် ဟု ထားမည်။
အကယ်၍ ဖ ထဲတွင် ဒေတာ ရှိလျှင် အောက်ပါတို့ကို လုပ်ဆောင်မည်။
ကိန်းရှင် ခ သည် ဖ ထဲမှ ဒေတာ ဖြစ်ပါစေ။
ခ ဟူသော လုပ်ဆောင်ချက်ကို ၁ တို့ဖြင့် လုပ်ဆောင်မည်။
လုပ်ဆောင်စရာများ ပြီးဆုံးပါပြီး။
ပရိုဂရမ် ပြီးဆုံးပါပြီး။
```

```text
မရှိ
၁
```

The function kind stands in parentheses before `ရှိကောင်းရှိနိုင်သော ဒေတာဆဲလ်`. A duplicate of a
function value is the same function, and `ဖ နှင့် ဂ သည် တစ်ခုတည်း ဖြစ်လျှင်` asks whether two
values are one function, as for [shared objects](../structs/objects.md#equal-or-the-same).
