Zaka, its website and its explorer build on the fonts, packages and crates below. With
thanks to all of these projects.

## Fonts

- **PDA10 Burmese Mono**: a Burmese monospace font from PhoenixDigitalArt. Portions ©
  Adobe. Special thanks to PhoenixDigitalArt for permission to use it on the website.
  [PhoenixDigitalArt on Facebook](https://www.facebook.com/PhoenixDigitalArt) ·
  [Release post](https://www.facebook.com/share/p/14td2Bwv4Jh/) ·
  [SIL Open Font License 1.1](https://openfontlicense.org)
- **Myanmar Sabae**: a Burmese font from Danh Hong.
  [Myanmar Sabae on GitHub](https://github.com/khmertype/Sabae) ·
  [SIL Open Font License 1.1](https://openfontlicense.org)
- **Sauce Code Pro (HTMM's Custom Font)**: a modified version of the Source Code Pro font
  from Adobe.
  [Source Code Pro on GitHub](https://github.com/adobe-fonts/source-code-pro) ·
  [SIL Open Font License 1.1](https://openfontlicense.org)
- **Other fonts**: the other fonts used in the font pickers come from Fontsource, most of them
  from Google Fonts. Each ships under its own open font license.
  [Fontsource](https://fontsource.org) · [Google Fonts](https://fonts.google.com)
